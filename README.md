<h3> ( RU ) Концепция калькулятора заключается в расчёте текущего нетворса по цене байбэка. Не у каждого человека есть подписка dota+, но думаю всем иногда интересна их текущая ценность. </h3>
Именно для этого я создал этот калькулятор, чтобы сидя в таверне или качая крипов в лесу вы могли посчитать сколько голды нафармили за время игры.
Он поддерживает 13 разных языков на всякий случай, хоть и имеет крайне узкий функционал.  
В их числе: Английский, Русский, Украинский, Испанский, Французский и другие.

## Скачать калькулятор можно [тут](https://github.com/Clurpy/Networth-calculator-Dota-2/archive/refs/heads/main.zip)

<h3> ( EN ) The concept behind this calculator is to calculate your current networth based on buyback cost. Not everyone has a Dota+ subscription, yet I imagine everyone is curious about their current value from time to time. </h3>
That is exactly why I created this calculator: so that while sitting in the tavern or farming creeps in the jungle, you can calculate how much gold you’ve earned during the match. It supports 13 different languages—just in case—even though its functionality is quite limited. These include English, Russian, Ukrainian, Spanish, French, and others.
